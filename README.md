# BearBank

Sitio web estático de BearBank.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (por ejemplo `BearBank`).
2. Sube `index.html` y este `README.md` a la raíz del repositorio.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages genere el enlace.

## Importante
Esta versión es la interfaz web con datos guardados en memoria del navegador (demostración local). **Todavía no está conectada a Supabase ni guarda datos de forma permanente**. Antes de usarla con información real de clientes o préstamos, debe implementarse autenticación, persistencia en base de datos y políticas de seguridad (RLS).
